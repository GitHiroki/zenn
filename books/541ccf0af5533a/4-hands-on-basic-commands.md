## よく使うコマンドを理解しよう

Dockerは、今やDocker DesktopをインストールしていればGUIで操作が可能です。
しかし、Dockerの本質を理解するためには、コマンドラインでの操作を覚えることが重要です。
ここでは、Dockerを操作する上でよく使うコマンドをいくつか紹介します。

## 4-1. Dockerのバージョンを確認する

```bash
docker --version
```

このコマンドは、インストールされているDockerのバージョンを表示します。
正直そんなに使いません。

## 4-2. Dockerのヘルプを表示する

```bash
docker help
```

このコマンドは、Dockerコマンドので利用可能なサブコマンドやオプションの一覧を表示します。
Dockerのコマンドは非常に多いので、困ったときに使うと便利です。
コマンドに慣れてる人は、`docker --help`と打つと思いますが、`--help`でもOKです。
また、サブコマンドに対しても使えます。

```bash
docker run --help
```

## 4-3. Dockerの情報を表示する

```bash
docker info
``` 

このコマンドは、Dockerのシステム全体の情報を表示します。
インストールされているコンテナ数、イメージ数、ストレージドライバの種類など、詳細な情報が得られます。
これは、あまり使いません。。

## 4-4. コンテナ一覧を表示する

```bash
docker ps
```

このコマンドは、現在実行中のコンテナの一覧を表示します。
`-a`オプションを付けると、停止中のコンテナも含めた全てのコンテナが表示されます。
めちゃくちゃ使います。
コンテナの起動後、停止後に確認するために使用します。

```bashbash
docker ps -a
```

`-a`もよく使います。
コンテナがが停止した後に、なぜ停止しなのか確認するために使用します。
また、余計なコンテナが残っていないか確認するために使用します。

## 4-5. イメージ一覧を表示する

```bash
docker images
```

このコマンドは、ローカルに保存されているDockerイメージの一覧を表示します。
`docker run`や`docker pull`で取得したイメージを確認するものです。

## 4-6. イメージを取得する

```bash
docker pull IMAGE[:TAG]
``` 

Dockerのイメージを取得するコマンドです。
`IMAGE`はイメージ名、`TAG`はバージョンを指定します。
`TAG`を省略すると、デフォルトで`latest`が使用されます。
例えば、`nginx`の最新バージョンを取得する場合は、以下のようにします。 

```bash
docker pull nginx
```

## 4-7. コンテナを起動する

```bash
docker run [OPTIONS] IMAGE [COMMAND] [ARG...]
```

このコマンドは、新しいコンテナを作成して起動します。
IMAGEを指定しているので、イメージがローカルに存在しない場合は、自動的に取得されます。
`IMAGE`は使用するDockerイメージを指定します。
`COMMAND`と`ARG`は、コンテナ内で実行するコマンドとその引数を指定します。
`OPTIONS`には、コンテナの設定を指定するための様々なオプションがあります。
例えば、`-d`オプションを使用すると、コンテナをバックグラウンドで実行できます。

```bashbash
docker run -d nginx
```

このコマンドは、`nginx`イメージを使用して新しいコンテナをバックグラウンドで起動します。
コンテナを起動する場合大抵は、バッググラウンドで起動します。

## 4-8. コンテナを起動する

```bash
docker start CONTAINER
``` 

このコマンドは、既存の停止中のコンテナを起動します。
コンテナが作られていない場合は、エラーになります。
`CONTAINER`は、コンテナIDまたはコンテナ名を指定します。
例えば、コンテナIDが`container1`のコンテナを起動する場合は、以下のようにします。    

```bash
docker start container1
```

## 4-9. コンテナを停止する

```bash
docker stop CONTAINER
``` 

このコマンドは、指定したコンテナを停止します。
`CONTAINER`は、コンテナIDまたはコンテナ名を指定します。
例えば、コンテナIDが`container1`のコンテナを停止する場合は、以下のようにします。

```bash
docker stop container1
```

## 4-10. コンテナを削除する

```bash
docker rm CONTAINER
```
このコマンドは、指定したコンテナを削除します。
`CONTAINER`はコンテナIDまたはコンテナ名を指定します。
例えば、コンテナIDが`container1`のコンテナを削除する
場合は、以下のようにします。

```bash
docker rm container1
```

コンテナを削除するだけなので、Pullしてきたイメージは残ります。

## 4-11. イメージを削除する

```bash
docker rmi IMAGE
```

このコマンドは、指定したDockerイメージを削除します。
`IMAGE`はイメージ名またはイメージIDを指定します。
例えば、イメージIDが`1234d090b25`のイメージを削除する
場合は、以下のようにします。

```bash
docker rmi 1234d090b25
```

また、複数削除する場合は以下のようにします。

```bash
docker rmi 1234d090b25 1234d090b26 1234d090b27
```

不要なイメージを消す時によく使います。
複数消せることを覚えておくと便利です。

## 4-12. コンテナのログを表示する

```bash
docker logs CONTAINER
``` 

このコマンドは、指定したコンテナのログを表示します。
`CONTAINER`はコンテナIDまたはコンテナ名を指定します。
例えば、コンテナIDが`container1`のコンテナのログを表示する場合は、以下のようにします。  

```bash
docker logs container1
``` 

また、起動しながらログをリアルタイムで表示する場合は以下のようにします。

```bash
docker logs -f -t -n 100 container1
```

`-f`オプションはログをフォローし、リアルタイムで表示します。
`-t`オプションは各ログエントリにタイムスタンプを追加します。
`-n`オプションは表示するログエントリの数を指定します。

コンテナが起動しない場合や、動作がおかしい場合にログを確認するために使用します。
私自身がトラブルシュートする際によく使うオプションです。
`-f`と`-n 100`は、tailfのように使えて便利です。

## 4-13. コンテナに接続する

```bash
docker exec -it CONTAINER COMMAND
```

このコマンドは、実行中のコンテナ内でコマンドを実行します。
`-i`オプションは標準入力を開いたままにし、`-t`オプションは擬似端末を割り当てます。
`CONTAINER`はコンテナIDまたはコンテナ名を指定し、
`COMMAND`はコンテナ内で実行するコマンドを指定します。
例えば、コンテナIDが`container1`のコンテナ内でbashシェルを起動する場合は、以下のようにします。

```bash
docker exec -it container1 bash
```

このコマンドは、コンテナ内で対話型のシェルを開くために使用します。
このようにすることでコンテナないにログインして、直接操作することができます。
何が起きているのかディレクトリの構成を確認したり、ファイルを編集したりすることができます。

## まとめ

今回は、Dockerを操作する上でよく使うコマンドを紹介しました。
これらのコマンドを覚えることで、Dockerの基本的な操作ができるようになります。
